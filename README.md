# Stream-Overlays

Grafiken und Overlays für den Twitch-Kanal Esel_99.

| Ordner / Datei | Inhalt |
|---|---|
| `szene.html`, `kamera.html`, `chat.html`, `gameplay-overlay.html` | Browserquellen für OBS |
| `umbra-stinger*.webm` | Szenenübergänge |
| `fertig/` | Fertige Grafiken: Twitch (Badges, Emotes, Panels, Profil- und Offline-Bild), Tipeee, Discord, Wallpaper |
| `streamelements/` | Alerts und Sounds für StreamElements |
| `tipeee/` | Vorlagen für die Tipeee-Seite |
| `vorlagen/` | Bearbeitbare Vorlagen für neue Grafiken |
| `bilder/` | Ausgangsbilder |
| `alt/` | Frühere Entwürfe, nur zum Nachschlagen |
